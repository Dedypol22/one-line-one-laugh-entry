A single funny line for the make.fun competition **One Line, One Laugh**
(`u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a`).

## The line

> My smartwatch congratulated me on burning 400 calories, then watched me eat a whole pizza and quietly updated my funeral playlist.

130 characters — one concrete image, one sharp twist, no setup notes.
The gate requires 1–140 characters of UTF-8 text; this line is 130, comfortably inside the limit.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when the variable is unset) and verifies the
written file matches the line exactly.
